# 人物補正（Final Cut Pro エフェクト）— 初版

肌・顔・体・腕・脚を部位ごとに補正する Final Cut Pro 用エフェクトです。FxPlug 4（Swift + Metal）で作っています。顔と体は Apple Vision で検出し、ワープと肌補正は GPU で処理します。

> ⚠️ **この初版は未ビルド・未テストです。** 作成環境が Linux で、Xcode と FxPlug SDK がありませんでした。最初のビルドで FxPlug のメソッド名や引数の差異が出る可能性があります。直し方は下の「最初にやること」にあります。

## 補正できる項目（スライダー）

`PersonRetouch/Plugin/ParamCatalog.swift` に全項目があります。項目の追加・変更はこのファイルを編集します。

| グループ | 項目 |
|---|---|
| 全体 | 全体の強度 / デバッグ表示 |
| 肌 | なめらかさ / 質感を残す / 補正の粒度 / 赤み・ニキビ跡 / 明るさ / 血色 |
| 顔の輪郭 | 顔の幅 / 顔の縦の長さ / 頬 / エラ / あごの長さ / あご先の幅 / 顔の傾き補正 |
| 額(デコ) | 額の広さ / 額のふくらみ |
| 眉 | 眉の高さ |
| 目 | 大きさ / 横幅 / 縦幅 / 目尻の上下 / 間隔 / 位置 |
| 鼻 | 鼻筋の太さ / 小鼻の幅 / 鼻の長さ / 鼻全体の大きさ |
| 口 | 口の横幅 / 唇の厚み / 口の位置 / 口角 |
| 中顔面 | 中顔面の長さ / 人中の長さ |
| 体・姿勢 | 肩の水平補正 / 体軸の傾き補正 / 肩幅 / 胸をへこます / ウエスト / 胴体全体 |
| 腕 | 二の腕 / 前腕 |
| 脚 | 太もも / ふくらはぎ / 脚全体 |

符号のルールは次のとおりです。

- 顔のスライダーは「＋で大きく・広く・高く・長く」、「－でその逆」です。
- 腕・脚・ウエストなど細さ系の項目は「＋で細く」です。

## 仕組み

```
フレーム ─▶ 縮小コピー(Metal) ─▶ Vision(顔ランドマーク / 体の骨格)
                                      │
スライダー値 ─▶ WarpBuilder ──────────┴─▶ ワープハンドル + 肌補正範囲
                                                      │
元フレーム ─▶ Shaders.metal(ワープ → エッジ保存の肌補正 → 色補正) ─▶ 出力
```

- **ワープ**は部位ごとの「ハンドル」を足し合わせる方式です。種類は拡大縮小、移動、軸に向けて細くする、回転の 4 つです。目の拡大は拡大縮小、小顔は輪郭上の点を内側へ移動、二の腕を細くするのは骨格の線分に沿って細くする、という具合です。
- **自然な肌補正**は、バイラテラルフィルタでシミやくすみを均し、毛穴レベルの細かい質感だけを戻す方式です（「質感を残す」で調整）。範囲は顔の楕円に限り、目・眉・唇は除外します。さらに肌色らしさでマスクするので、髪や背景には効きません。
- **デバッグ表示**をオンにすると、検出した位置（赤い点）、影響範囲（緑の輪）、肌補正の範囲（青）が出ます。最初の動作確認に使ってください。

## ビルドと導入（Mac）

1. [FxPlug SDK](https://developer.apple.com/final-cut-pro/) をインストールします（`/Library/Developer/Frameworks/FxPlug.framework` ができます）。
2. `brew install xcodegen`
3. `cd PersonRetouch && xcodegen`（`project.yml` に自分の `DEVELOPMENT_TEAM` を入れておきます）
4. `PersonRetouch.xcodeproj` を開いてビルドし、できた `PersonRetouch.app` を `/Applications` に置いて 1 回起動します。
5. Final Cut Pro を再起動し、エフェクト › 人物補正 › 人物補正 をクリップにドラッグします。

## 最初にやること

1. ビルドエラーを直します。FxPlug のメソッド名が合わない場合は、SDK 付属の「FxPlug 4 Metal」サンプルに合わせます。直す可能性が高いのは次の箇所です。
   - `PersonRetouchPlugIn.swift` の `FxTileableEffect` の各メソッド
   - `metalTexture(for:)` / `deviceRegistryID`
   - `FxPrincipal.startServicePrincipal()`
2. デバッグ表示をオンにして、検出位置が顔に合っているか確認します。**画像が上下逆の場合**は、`Shaders.metal` の `vs_full` の uv.y と、`WarpBuilder` の `1 - y` の向きを確認します。
3. 各スライダーの効き量は `WarpBuilder.swift` の係数（`0.10 * faceW` など）で調整します。数値は未調整の仮置きです。

## 既知の制限と次の一手

- **フレーム間の揺れがあります。** ランドマークはフレームごとに検出します。時間方向の平滑化（解析ボタンで一括解析してキャッシュ）が必要です。
- **タイル分割は未対応です。** 常に画像全体を処理します。
- **体の補正は正面〜斜めの全身向けです。** 胸をへこます機能は、現状は等方的な縮小です。横向きの胸の厚みを抑える専用処理は未実装です。
- 輪郭（顔・体）の外側にある背景は、ワープで一緒に歪みます。人物セグメンテーションで背景の歪みを抑える処理は未実装です。
- 脚の長さの補正と、まぶた・涙袋・唇の色などの補正は未実装です。
- 顔の検出は最大 3 人、体の検出は最大 2 人までです。
